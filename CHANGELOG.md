## [0.1.0] - 2026-07-27

### Added
- Initial project setup and repository structure
- Frontend foundation: Next.js with TypeScript and Tailwind CSS
- Backend foundation: FastAPI with Python and Pydantic
- Project documentation:
  - PROJECT_SOURCE_OF_TRUTH.md - Project vision and architecture
  - TEAM_ROLES_AND_DELIVERABLES.md - Team structure and responsibilities
  - AGENTS.md - AI development guidelines
  - docs/SETUP.md - Development environment setup
  - docs/ARCHITECTURE.md - System architecture documentation
- Knowledge base directory structure for Centennial College information
- Configuration files:
  - .gitignore - Git ignore rules
  - .env.example - Environment variable templates
  - frontend/tsconfig.json - TypeScript configuration
  - frontend/tailwind.config.ts - Tailwind CSS configuration
  - backend/config.py - Backend configuration management
- Frontend components:
  - Next.js App Router setup
  - Global CSS and Tailwind integration
  - Error and 404 page components
  - Basic home page
- Backend components:
  - Health check endpoints
  - CORS middleware configuration
  - API route structure
  - Pydantic schema examples
